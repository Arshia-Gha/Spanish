# Marsupilami ChatGPT Work Pet — Final HQ Package

This package contains the final high-quality Marsupilami pet artwork and animations.

## Final pet files

- `final-pet/marsupilami-hq-spritesheet.png` — validated 1536×1872 transparent sprite sheet used by ChatGPT Work.
- `final-pet/contact-sheet.png` — all animation frames arranged by state.
- `final-pet/all-states.gif` — combined looping preview of all states.
- `final-pet/all-states.mp4` — MP4 preview of all states.
- `final-pet/idle-jump-idle.gif` — transition-quality preview.
- `final-pet/*.gif` — individual state animations: idle, run left/right, wave, jump, failure, waiting, active work, and review.
- `final-pet/still-*.png` — representative transparent still frames.

## Best source strips

The `best-source-strips` folder contains the nine full-resolution source strips used to build the final sprite sheet. These retain the original magenta chroma-key background and are named by animation state.

## Animation behavior

Marsupilami uses its long tail to collect a task card, work at a laptop, stamp a task complete, inspect a checklist, and signal when user input is needed.
