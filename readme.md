# Spanish Verb Study Dashboard 🇪🇸

A simple web-based tool for practicing Spanish verbs and vocabulary.

## Features

- Spanish verb conjugation practice
- Vocabulary training
- Interactive exercises
- Progress tracking in the browser
- Lightweight and fully offline-compatible

## Usage

Open `index.html` in your browser, or visit the GitHub Pages version:
https://github.com/Arshia-Gha/Spanish
